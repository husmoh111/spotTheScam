# Spot the Scam

A multiple-choice scam awareness game built with Node.js and no installed dependencies.

## Run

Use Node.js 22.13 or later (Node.js 24 recommended):

```sh
npm start
```

Open http://localhost:3000. To use the QR code on a phone, connect both devices to the same network and allow incoming connections to port 3000 in your firewall. The code points to the server's first non-loopback IPv4 address; if the machine has multiple network adapters, use the displayed address to check that it is reachable. QR images are generated by api.qrserver.com, so displaying them requires internet access and shares the game URL with that service.

Players can register with a name and password, log in, play without an account, and save scores when logged in. Accounts and scores are stored in the SQLite database `spotthescam.sqlite` beside the server. Existing `data.json` accounts and scores are imported automatically on the first database startup; the original file is kept as a backup. Back up the database using SQLite’s backup tools or stop the server before copying it. Passwords are salted and hashed. Sessions are held in memory and reset when the server restarts.

Each round randomly selects 15 distinct topics from 30 scenario topics. The question bank contains 150 question variations (five prompts per topic). The leaderboard is intended for friendly local play: scores are submitted by the browser and are not cheat-resistant. This local HTTP server is not designed for public internet deployment; production use needs HTTPS, persistent sessions, rate limiting, server-validated game results, and a production database.
